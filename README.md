# Эхо кода (Echoes of the Code)

2D-платформер с элементами головоломки и стелса в сеттинге киберпанк. Прототип, выполненный в рамках производственной (технологической, проектно-технологической) практики, 7 семестр.

> Хакер по прозвищу **Призрак** проникает в виртуальную реальность корпорации «Нексус», чтобы восстановить утерянные данные о своём прошлом и остановить вышедший из-под контроля ИИ.

**Играть в браузере:** откройте `index.html` (или ссылку GitHub Pages после публикации репозитория).

## Возможности прототипа

| Механика | Реализация |
|---|---|
| Бег, прыжок, двойной прыжок | «Койот-тайм» 0,1 с, буфер прыжка 0,12 с, высота прыжка зависит от длительности нажатия |
| Взлом терминалов | Мини-игра: повторить последовательность стрелок за отведённое время; открывает двери и отключает лазеры |
| Замедление времени | Мир замедляется до 35 %, игрок — до 80 %; расходует энергию, восстанавливается после паузы |
| Стелс | Дроны и камеры с конусами обзора, линия видимости, тени-укрытия, шкала подозрения → тревога |
| Здоровье | Сегменты здоровья, неуязвимость после урона, точки восстановления |
| Инвентарь | 5 предметов-имплантов (как в концепте), до 3 активных одновременно, сортировка по редкости |
| Уровни | 3 сектора: «Неоновые крыши» (обучение), «Серверные фермы», «Ядро ИИ» (финал) |

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Бег | ← → / A D | стик, D-pad |
| Прыжок, двойной прыжок | Пробел / W / ↑ | A |
| Спрыгнуть с платформы | ↓ + прыжок | вниз + A |
| Взлом | E | X |
| Замедление времени | Shift / K (удерживать) | RB / RT |
| Инвентарь | I / Tab | Y |
| Пауза | Esc / P | Start |
| Отладочная панель | F3 | — |

На сенсорных устройствах появляются экранные кнопки.

## Технологии

- HTML5 Canvas 2D, JavaScript (ES2020), Web Audio API, Gamepad API.
- Без движков, библиотек и сборки: игра запускается из папки или с любого статического хостинга.
- Внутреннее разрешение 480×270, масштабирование средствами CSS (`image-rendering: pixelated`).
- Физика с фиксированным шагом 1/120 с — одинаковое поведение на мониторах 30–240 Гц.
- Звук и музыка синтезируются, графика рисуется кодом: нет внешних ассетов, кроме фона меню.

## Структура

```
index.html          — разметка, все экраны интерфейса
css/style.css       — стили и анимации интерфейса
js/util.js          — утилиты, предметы, сохранение
js/levels.js        — описание уровней (builder)
js/world.js         — симуляция: физика, враги, стелс, взлом (без DOM)
js/sprites.js       — пиксель-арт и его пререндер
js/audio.js         — синтез звуков и музыки
js/input.js         — клавиатура, геймпад, сенсор
js/render.js        — отрисовка, параллакс, эффекты
js/ui.js            — меню, HUD, инвентарь, взлом, диалоги
js/main.js          — игровой цикл, состояния, статистика
tests/index.html    — автотесты симуляции (35 тестов)
```

## Тестирование

Откройте `tests/index.html` — тесты выполняются в браузере за доли секунды и проверяют физику (высоту и дальность прыжков, столкновения), стелс, взлом, урон, проходимость всех уровней и производительность симуляции.

Клавиша **F3** в игре включает отладочную панель: FPS, время кадра, число частиц и пуль, хитбоксы.

## Запуск локально

Достаточно открыть `index.html` в браузере. Для корректной работы шрифтов и сохранений лучше через любой статический сервер:

```
python -m http.server 8000
```

## Публикация на GitHub Pages

1. Создать репозиторий и загрузить содержимое папки.
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
